# Agent instructions

Guidance for AI agents working on `git2html`. Read this before modifying the codebase, documentation, or build system.

## Commands

- Build static binary and man page: `make`
- Run the full test suite against the compiled static binary: `make test`
- Build reproducible release tarballs: `make dist`
- Verify user dependencies: `make check-user-deps`
- Verify developer dependencies: `make check-dev-deps`
- Regenerate man pages from scdoc source: `make man`
- Remove all build artifacts: `make clean`
- Install binary and man page: `make install [PREFIX=/usr/local] [DESTDIR=...]`

## Architecture & Layout

- **`src/`**: Project source code:
  - `src/git2html.lua`: Core application logic.
  - `src/git_utils.lua`: Git interaction utilities.
  - `src/bundle_main.c`: C entry point for the standalone static executable.
  - `src/bundle_data.h`: Declarations for embedded modules and themes.
- **`build/`**: Ephemeral build artifacts (never committed, wiped by `make clean`):
  - `build/git2html`: Compiled standalone static executable.
  - `build/lpeg.so`: Dynamic LPeg library for host Lua test runner.
  - `build/bundle_data.c`: Embedded byte arrays generated by `tools/gen_bundle.lua`.
  - `build/obj/`: Compiled object files.
- **`vendor/`**: Vendored third-party dependencies:
  - `vendor/lua`: C source for Lua 5.4 runtime embedded in the static binary.
  - `vendor/lpeg`: C source for LPeg pattern-matching library.
  - `vendor/lunamark`: Markdown to HTML converter.
  - `vendor/cosmo`: Templating engine required by lunamark.
  - `vendor/re.lua`: LPeg regex module required by cosmo.
  - `vendor/syntaxhighlight`: Syntax highlighter for source code and markdown fences.
- **`doc/`**: Documentation and manual pages:
  - `doc/man/git2html.1.scd`: Man page source in scdoc format.
  - `doc/man/git2html.1`: Pre-rendered roff man page (committed so users do not need `scdoc`).
  - `doc/tasks/`: Taskmark project task tracking (`active.tm.md`, `completed.tm.md`).
- **`themes/`**: Plain CSS stylesheets conforming to the WebVeld property subset.
- **`test/`**: Test suite executed by `test/runner.lua` against the compiled static binary.

## Testing & Quality Rules

- Practice Test-Driven Development (TDD). Verify failures before implementing fixes.
- `make test` runs tests against the compiled static executable (`build/git2html`), testing the exact artifact users install.
- Test output must be concise with one line per test case, starting with `[PASS]`, `[FAIL]`, or `[SKIP]`.
- All build artifacts must stay inside `build/` so `make clean` only deletes `build/`.
- Pre-generated man pages are tracked in git; `test/man.test.lua` ensures committed man pages stay in sync with `doc/man/git2html.1.scd`.
- Zero tolerance for compiler warnings.

## External Path Exceptions

The pre-commit screen flags literal `~/...` tokens; the following are vendored regex character sets rather than filesystem paths:
- `~/_`
- `~/`
